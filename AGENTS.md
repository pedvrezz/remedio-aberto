# AGENTS.md

- Trabalhe somente dentro deste repositório.
- Não invente dados, fontes, licenças ou resultados de testes.
- Use TDD em comportamento novo e execute `make check` antes de commit.
- Lite/loopback é o padrão. Exposição externa é sempre opt-in.
- Nunca colete PII, prontuários, prescrições ou dados sensíveis de saúde.
- Cada dado futuro exige provenance e distinção explícita de campo ausente.
- Não crie arquitetura ou SDK vazio para atender roadmap.
