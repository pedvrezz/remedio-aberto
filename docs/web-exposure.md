# Exposição web opcional

Não implementada nem recomendada na Fase 0. Uma futura instância pública exigirá autenticação administrativa, TLS, reverse proxy, rate limit, atualização de dependências, backups testados e revisão de headers/CORS. Caddy, Nginx, Traefik e Cloudflare Tunnel são opções do operador, nunca configuração automática do projeto.
