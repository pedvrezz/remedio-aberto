# Contribuindo

1. Abra uma issue/discussão antes de grandes mudanças.
2. Crie branch; nunca faça commit direto em `main` para mudanças P1+.
3. Execute `make setup` e `make check`.
4. Use Conventional Commits e commits atômicos reais.
5. Não inclua datasets grandes, `.env`, credenciais ou dados pessoais.
6. Nova fonte exige atualização de `docs/data-sources.md`, evidência oficial, fixtures pequenas e testes do parser.
7. PRs de forks não devem receber secrets.
